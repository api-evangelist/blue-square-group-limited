# GRVT (Blue Square Group Limited)

> GRVT (pronounced "gravity") is a licensed hybrid crypto derivatives exchange that pairs a
> high-performance central limit order book with self-custody settlement on a zkSync-based L2.
> It offers a public Market Data API and an authenticated Trading API (REST + WebSocket) covering
> perpetual futures, spot, positions, transfers, and on-chain vaults. Blue Square Group Limited is
> the corporate entity behind GRVT; the engineering org is Gravity Technologies (Singapore).

## APIs
- [Market Data API](https://market-data.grvt.io): Public market data — instruments, tickers, orderbooks, trades, candlesticks, funding rates.
- [Trading API](https://trades.grvt.io): Authenticated trading — orders, positions, margin, transfers, withdrawals, vault investment.
- [Auth / edge](https://edge.grvt.io): API-key login endpoint (POST /auth/api_key/login).
